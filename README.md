sebelum jalanin "npm run dev" install dulu packages yang perlu, dada yang perlu di install di root ada juga yang perlu di install di server

root packages:
npm install tailwindcss @tailwindcss/vite
npm install concurrently

server packages (cd server):
npm install express cors bcryptjs jsonwebtoken
npm install pg dotenv

kalau setelah install semua packages ini masih ada error beri tau aku

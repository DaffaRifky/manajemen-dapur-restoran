Sistem Manajemen Dapur Restoran ini dirancang sebagai aplikasi web berbasis multi tenancy yang fokus untuk mendigitalisasi alur pesanan dan operasional restoran secara terintegrasi. Lingkup pengerjaan proyek ini dimulai dari analisis kebutuhan sistem buat nentuin siapa saja aktor yang terlibat seperti Owner, Waiter, Koki, dan Kasir, serta apa saja fitur yang dibutuhkan berdasarkan hak akses masing-masing.
